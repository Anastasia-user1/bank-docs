# Настройка аккаунта в Nova Bank

**Для начала настройки аккаунта:**

1. Зайдите в личный кабинет.
2. Перейдите в раздел **"Профиль"**.
3. Выберите **"Настройка аккаунта"**

---

## Шаги настройки аккаунта банка:

1. **Введите почту**  
   _Пример:_ `example@mail.com`

![Почта](../img/Account Set Up Email.png)

2. **Выберите тип учётной записи**  
   - Физическое лицо  
   - Юридическое лицо  
   - VIP клиент

3. **Добавьте адрес регистрации**  
   _Пример:_ г. Пермь, ул. Ленина, д. 1

4. **Добавьте личные данные**  
   - ФИО: Иванов Иван Иванович  
   - Дата рождения: 01.01.1990

**Поздравляем! Ваш аккаунт готов к работе.**
